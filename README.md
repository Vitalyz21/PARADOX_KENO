# PARADOX KENO

Самостоятельная демонстрационная игра для запуска на Render.

## Механика
- Поле: 5 рядов × 8 колонок = 40 чисел (1–40).
- Игрок выбирает от 1 до 10 чисел.
- Сервер вытягивает 10 уникальных чисел.
- Выплата рассчитывается по демонстрационной таблице коэффициентов в `server.js`.
- Баланс виртуальный, стартовый баланс — 1000 кредитов.
- Сервер публикует SHA-256 хеш server seed до раунда и использует HMAC-SHA256 для перемешивания.

## Локальный запуск
Требуется Node.js 20 или новее.

```bash
npm start
```

Откройте http://localhost:3000

## Развёртывание на Render
1. Создайте отдельный GitHub-репозиторий `PARADOX_KENO`.
2. Загрузите содержимое этой папки в корень репозитория.
3. В Render выберите **New + → Web Service** и подключите репозиторий.
4. Build Command: `npm install` (зависимостей нет, команда допустима).
5. Start Command: `npm start`.
6. Выберите Node runtime и создайте сервис.

## Важно
Это готовая демо-сборка для тестирования интерфейса и механики, не платформа для реальных денежных ставок. Баланс хранится в памяти процесса и сбрасывается при перезапуске сервера. Для публичной эксплуатации нужны постоянная база данных, авторизация, защита от злоупотреблений, аудит выплат, ротация и раскрытие seed после раундов, независимая проверка Provably Fair и юридическая проверка требований лицензирования. Таблица выплат — демонстрационная и не является таблицей Stake.
